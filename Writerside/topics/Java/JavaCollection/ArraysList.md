## java.util.Arrays

java.util.Arrays 是 Java 标准库中提供的一个工具类，它包含了一些用于操作数组的静态方法。这些方法可以用来进行数组的排序、查找、复制、填充、比较等常见的数组操作。它的功能非常全面，使得操作数组更加简洁高效。

### 使用场景
* 数组排序：如果你有一个数组，需要按升序或降序排列，可以直接使用 Arrays.sort()。
* 数组查找：使用 binarySearch() 查找已排序数组中的元素。
* 数组复制：使用 copyOf() 来复制数组，避免手动编写循环。
* 数组填充：使用 fill() 来填充数组，快速初始化数组。
* 数组比较：使用 equals() 判断两个数组是否相等。
* 转化为集合：使用 asList() 可以将数组快速转化为 List，从而利用 List 提供的各种方法。(需要注意的是`Arrays.asList()`方法，返回的是原数组的视图，无法进行增加或者删除元素的操作)
